## 3. Real-Time Engagement (Likes, Comments & Reporter Stats)

  - Created `clipping_comments` table structure and Postgres trigger to synchronize total comment counts.
  - Connected comment metrics to the Reporter Stats dashboard so reporters can view comments on their clippings.

---

## 4. Unique View Tracking (Database-Level Protection)
- **Problem:** Re-visiting a news clipping repeatedly incremented the view count.
- **Solution (`supabase_views.sql`):**
  - Created `public.clipping_views` table with a composite primary key `(clipping_id, user_id)`.
  - Enforced DB-level unique constraint (`23505` error code caught silently on frontend) so that a user viewing the same clipping multiple times is only counted **once**.
  - Added Postgres trigger on `clipping_views` to automatically update `views_count` on `clippings` table only when a genuinely new user views a clipping.

---

## 5. Image Upload Limit Mismatch Resolution
- **Problem:** Reporter image upload dialog displayed error *"File exceeds maximum allowed size of 10MB"* while specifications specified 50MB.
- **Solution:**
  - Updated `generation.service.ts` pre-flight file size check from `10 * 1024 * 1024` to `50 * 1024 * 1024` (50MB).
  - Updated HTTP 413 error handler to reflect the correct 50MB limit.

## 6. Daily Newspaper PDF Generator (A3 BroadSheet Telugu Layout)
- **Super-Admin Access & Security:**
  - Added **"Generate News PDF"** button and **"Daily Editions"** tab to the Super Admin Dashboard in `AdminScreen.tsx`.
  - Enforced server-side JWT authorization check (`verify_superadmin_request`) on all `/api/v1/admin/daily-newspaper/*` backend endpoints.
- **Date & Article Selection:**
  - Defaulted edition date to today in `Asia/Kolkata` (`YYYY-MM-DD`). Allows picking any date.
  - Filtered clippings by published date in Asia/Kolkata (`is_posted = true`, excluding drafts, rejected, and deleted items).
  - Allows selecting/excluding, reordering (up/down), and choosing the **Lead Story** (slot 4).
- **Required Selected Publication Logo & Immutable Snapshots:**
  - Super admin selects from configured publication logos (RTI Express, Spot News 24x7, Bharath Reporter, etc.).
  - Displays exact selected logo in masthead and continuation headers with `object-fit: contain`, preserving colors and proportions.
  - Saves an immutable snapshot of `logo_url` and publication branding in `daily_editions` DB table so future logo changes do not affect past PDFs.
- **A3 Page Layout & Grid Engine:**
  - Print size: A3 Portrait (`297mm x 420mm`).
  - 10-article per page allocation (10, 10, 10...).
  - Four-column 10-slot layout grid: Band 1 (Top 2x2 cols), Band 2 (Slot 4 Lead Story centre 2 cols), Band 3 (Lower-middle), Band 4 (Bottom 3-col feature).
  - Dynamic rebalancing on partially filled pages (1 to 9 articles).
  - Page 1 Masthead with red (`#D60000`) and yellow (`#FFCC00`) accent borders and dark green (`#006633`) edition information strip.
  - Continuation header on pages 2+ with selected logo and `Page X of Y` indicator.
- **Telugu Typography & Headlines:**
  - Embedded Google Fonts `Noto Serif Telugu`, `Mandali`, `Cinzel`.
  - Headlines styled in bold red, dark blue, dark magenta, dark green, or black following Telugu broadsheets.
  - Highlight lists styled with red triangular bullet markers (`▶`).
- **Python Playwright A3 PDF Engine & Database:**
  - Built `daily_newspaper_generator.py` using Playwright Chromium to render HTML to sharp A3 vector PDFs.
  - Created `daily_editions` database table to track generated editions, page counts, versions, and PDF URLs.
- **Interactive Super Admin Modal & Preview:**
  - 4-step wizard modal (`DailyNewspaperGeneratorModal.tsx`) with live A3 HTML preview and page pagination.
